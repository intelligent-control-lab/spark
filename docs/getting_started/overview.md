# Overview

SPARK is a modular robotics framework for combining robot models, execution
backends, tasks, control policies, safety algorithms, and complete application
pipelines. It supports MuJoCo, Isaac, direct dynamics execution, and selected
physical robots.

## Main capabilities

- Multiple robot embodiments and control dimensions
- First- and second-order dynamics
- Teleoperation and autonomous goal tasks
- Classical, optimization-based, and learned control policies
- Collision monitoring and safety filtering
- Reusable simulation and hardware pipelines

See {doc}`../modules/robot` for supported embodiments and
{doc}`../modules/agent` for execution backends.
